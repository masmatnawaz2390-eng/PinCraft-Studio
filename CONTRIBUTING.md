# Contributing to PinCraft Studio

We're excited to have you contribute! This document outlines how to participate.

## Code of Conduct

We are committed to providing a welcoming, inclusive environment. Be respectful and constructive.

## How to Contribute

### Reporting Bugs
1. Check if the bug has already been reported
2. Provide a clear, descriptive title
3. Include steps to reproduce
4. Specify your environment (OS, Node version)
5. Add screenshots or logs if applicable

### Feature Requests
1. Describe the feature and its use case
2. Explain how it improves the tool
3. Provide examples if possible

### Code Contributions
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Commit with clear messages: `git commit -m 'Add feature X'`
4. Push to your fork
5. Open a Pull Request with a clear description

### Documentation
- Typos and clarity improvements welcome
- Add examples for complex concepts
- Update README if adding features

## Development Setup

```bash
git clone https://github.com/yourusername/PinCraft-Studio.git
cd PinCraft-Studio
npm install
npm test
```

## Style Guide
- Use ES6+
- Follow existing code patterns
- Add comments for complex logic
- Write tests for new features

## Pull Request Process
1. Update documentation
2. Ensure tests pass: `npm test`
3. Keep commits clean and descriptive
4. Write a clear PR description

Thank you for contributing! 🎉
